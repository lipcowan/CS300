#### What was the problem you were solving in the projects for this course?
Reviewing the different data structures commonly worked with and their appropriate use-cases.

#### How did you approach the problem? Consider why data structures are important to understand.
There are a lot of things to consider when planning a project, among them are the time and storage requirements of the client. The data structures used in a program or application can impact the performance of the application so it's important to consider when planning and writing your code that the data structure is appropriate.

#### How has your work on this project expanded your approach to designing software and developing programs?
I've been able to plan ahead for storage and time requirements better. Also, I'm a lot more confident in using the terminal/console.
